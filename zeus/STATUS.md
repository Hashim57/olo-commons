## Open decisions
- Base model: Mistral 7B Instruct v0.2 (Apache 2.0) since v6, because it is the base Cloudflare Workers AI runs uploaded LoRA adapters on (`@cf/mistral/mistral-7b-instruct-v0.2-lora`), so one training run gives both the measured adapter and the served one. Qwen2.5 (7B and the 1.5B sibling) stays the Mac and offline choice. Re-checked every Monday; last check 2026-11-02, no change.
- Atom cap: the Commons passed the 7,000-atom cap on 2026-11-10, and the cap keeps the oldest usable atoms, so no atom added since enters a training build. `build_dataset.py --cap-mode` (since 2026-11-11) offers `newest` and `hash` (a stable sample over the whole Commons) beside the default `oldest`; Hashim's call which one the cloud workflow trains with, or whether to raise the cap again (the 7,000 build trains v19 in about 117 minutes on an A100).
- Contradiction quality: rule-made for the bulk; the hand-written gold set under `data/gold/` started on 2026-10-24 (10 examples) and should grow every run. `validate_gold.py` guards it.
