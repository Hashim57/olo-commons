Hand-written examples, one JSON object per line in any `*.jsonl` file here, same shape as `data/train.jsonl`. These are the highest-value examples Zeus trains on: contradictions a rule could not write, claims that look covered but are not, multi-passage support. Keep provenance on every passage. Never include text you do not have the right to publish. Check a file before committing it with `python3 zeus/validate_gold.py` (every evidence quote must be an exact substring of its passage; `not_covered` has empty evidence).

## Files

- `gold-2026-10-24.jsonl`: 10 examples over 12 PubMed atoms (passage `id` is the first 8 characters of the atom id; `atom_id` carries the full id). Four contradictions that change a relation, not a number (more/less cost-effective, intensifies/weakens, limited/close attention, focus/ignore); three near-miss not_covered claims that sit next to a passage without being stated by it (every year versus episodes, a comparison no passage makes, "can protect" versus "has protected"); two supported claims that need two passages; one supported paraphrase with no shared wording. Passage texts are excerpts read through the public olo-query API (title plus the first three sentences of the summary, each cut at 120 characters, cuts marked with " ... "), so they are shorter than the atoms themselves.
